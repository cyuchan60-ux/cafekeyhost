# 새내기 카페 키오스크 (Campus Cafe Kiosk)

대학교 1학년 새내기 학생이 개발한 캠퍼스 카페 터치 키오스크 웹 애플리케이션입니다.

## 📌 주요 기능
1. **4대 인기 메뉴 & 5,000원 균일가** (아아, 라떼, 아이스티, 레몬에이드)
2. **옵션 선택**: 포장 여부(매장/포장), 얼음량(보통/많이/적게), 당도(기본/덜 달게/달게)
3. **실시간 장바구니 및 총 결제 금액 계산** (잔당 5,000원)
4. **포인트 적립 단계**: 주문 전 "포인트 적립을 하시겠습니까?" 질문 후 가상 터치 키패드로 번호 입력 (5% 적립)
5. **주문 완료 및 영수증**: 대기 주문 번호 발행, 최종 결제 금액 명시, 포인트 적립 내역 확인
6. **Excel (.xlsx) 다운로드 기능**:
   - **이번 주문 엑셀 저장**: 주문 번호, 일시, 상품명, 수량, 총 결제 금액, 포인트 적립 여부 및 휴대폰 번호가 기록된 영수증 엑셀 파일
   - **누적 전체 장부 엑셀**: 키오스크 전체 주문 로그가 정리된 엑셀 파일

## 💻 Visual Studio / VS Code에서 실행하는 방법

### 1. 사전 요구사항 (Prerequisites)
- [Node.js (v18 이상 권장)](https://nodejs.org/)가 컴퓨터에 설치되어 있어야 합니다.
- [Visual Studio Code (VS Code)](https://code.visualstudio.com/) 또는 Visual Studio

### 2. 프로젝트 열기 및 설치
1. 다운로드받은 압축 파일(`campus-cafe-kiosk-vscode.zip`)의 압축을 원하는 폴더에 풉니다.
2. **VS Code**를 실행한 뒤, 상단 메뉴에서 **[파일(File)] → [폴더 열기(Open Folder...)]**를 클릭하여 압축 해제한 폴더를 선택합니다.
3. 상단 메뉴에서 **[터미널(Terminal)] → [새 터미널(New Terminal)]** (단축키: `Ctrl + ~`)을 엽니다.
4. 아래 명령어를 터미널에 입력하여 필요한 라이브러리를 설치합니다:
   ```bash
   npm install
   ```

### 3. 로컬 개발 서버 실행
설치가 완료되면 다음 명령어로 로컬 서버를 실행합니다:
```bash
npm run dev
```

터미널에 표시되는 로컬 주소(기본 `http://localhost:3000`)를 웹 브라우저로 열면 키오스크 앱이 즉시 실행됩니다!
